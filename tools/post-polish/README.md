# Post Polish — LinkedIn and Viva Engage

Prepare posts with formatting, emoji, and cleaner spacing, then copy them into your publishing app.

## Use in your browser

[Open Post Polish with HTML Preview](https://htmlpreview.github.io/?https://github.com/maduroq/tiny-tools/blob/main/tools/post-polish/index.html)

HTML Preview is a third-party service and needs an internet connection to load the tool.

## Use offline

Download this repository with **Code → Download ZIP**, extract it, and open `tools/post-polish/index.html` in a modern browser. Alternatively, open [index.html](index.html) on GitHub and choose **Download raw file**, then open the downloaded file.

## Write and format a post

1. Choose **LinkedIn** or **Viva Engage**.
2. Write or paste your text into the editor.
3. Select text and apply bold, italic, or underline. Add emoji, paragraph spacing, or clean up extra spaces as needed.
4. Select **Copy for LinkedIn** or **Copy for Viva Engage**, then paste into the destination app and review before publishing.

**Copy plain text** is also available. If copying is blocked by your browser, select the editor text and press **Ctrl+C** (or **Cmd+C** on Mac).

## Features

- LinkedIn mode transforms selected text into Unicode bold, italic, or combining underline characters.
- LinkedIn copying inserts invisible Braille blank characters on empty lines to help retain paragraph spacing.
- Viva Engage mode uses rich-text editing and copies HTML with a plain-text alternative where supported.
- Quick emoji buttons, spacing cleanup, paragraph spacing, and word and character counts.
- Light and dark theme buttons; this version opens in light mode.

Spacing cleanup and paragraph spacing replace the editor content with text, removing rich-text styling. Unicode-styled letters remain Unicode characters when copied as plain text. Clipboard behavior and pasted formatting depend on the browser and destination app.

## Privacy

The standalone tool contains no network requests, external dependencies, analytics, or persistent application storage. It does not connect to LinkedIn or Viva Engage or publish posts; you copy and paste the result yourself. Copy buttons write to your clipboard. Drafts and theme choices are not saved by the app.
