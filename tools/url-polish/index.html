01 / Convert

Encode & decode

Inspect a long URL or prepare text for use inside one.

One layer per click. Component decoding is useful for reading SharePoint links; decoded separators can change a URL's meaning. Whole-URL mode keeps reserved separators encoded when decoding. Form mode treats + as a space.

02 / Share

A link, ready to paste

Choose a plain URL, Markdown, or an HTML link.

HTML copies source code, not rich text. URLs must start with https:// or http://. Existing query parameters and access tokens are retained.
