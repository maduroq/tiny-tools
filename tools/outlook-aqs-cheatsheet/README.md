# Outlook AQS · Offline Cheatsheet

A local reference for Outlook Advanced Query Syntax (AQS), with searchable recipes and a query builder.

## Run it

1. Download the repository using **Code → Download ZIP** and extract it.
2. Open `tools/outlook-aqs-cheatsheet/index.html` in your browser.
3. Filter recipes by keyword or category, then use **Copy** beside a query.
4. Paste the query into Outlook search and review the results.

Alternatively, download [index.html](index.html) using GitHub's **Download raw file** button and open it locally. GitHub's source preview does not run the tool.

## Features

- Recipes for cleanup, meetings, people, content, files, and dates.
- Keyword filtering and category buttons.
- Query builder for sender, subject, body, phrases, dates, and status filters.
- Copy buttons and a compact operator reference.
- Light and dark themes, initially based on browser preference unless a saved choice exists.
- Print styles for the reference and recipes.

## Privacy

The cheatsheet runs offline with no external scripts, fonts, analytics, or network dependencies. It does not connect to your mailbox or execute queries. Copy buttons write the selected query to your clipboard. Your theme choice is saved in browser local storage; builder inputs are not saved by the app.

## Compatibility

The included notes explain that Outlook clients and date locales can differ. Check each query's results in your Outlook client before taking bulk actions. This import preserves the original cheatsheet; its queries have not been independently revalidated as part of the import.
