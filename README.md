# Maduroq Tiny Tools

Small tools for everyday problems.

A growing collection of focused utilities by Quiriën Maduro. Each tool has its own folder, practical instructions, and source you can inspect.

## Use in your browser — no download

You can open these HTML tools directly in your browser using [GitHub HTML Preview](https://htmlpreview.github.io/):

1. Navigate to a tool's folder in this repository and open its `index.html` file.
2. Copy the URL from your browser's address bar.
3. Open [htmlpreview.github.io](https://htmlpreview.github.io/), paste the copied URL, and select **Preview**.

Alternatively, add `https://htmlpreview.github.io/?` before the GitHub file URL. These links are ready to use:

- [Open Flash Speed Reader](https://htmlpreview.github.io/?https://github.com/maduroq/tiny-tools/blob/main/tools/flash-speed-reader/index.html)
- [Open Private Image Resizer](https://htmlpreview.github.io/?https://github.com/maduroq/tiny-tools/blob/main/tools/private-image-resizer/index.html)
- [Open Outlook AQS · Offline Cheatsheet](https://htmlpreview.github.io/?https://github.com/maduroq/tiny-tools/blob/main/tools/outlook-aqs-cheatsheet/index.html)

HTML Preview is a third-party service and requires an internet connection to load the tool. For fully offline use, download the HTML file as described below.

## Download for offline use

Download this repository using **Code → Download ZIP**, extract it, and open the tool's `index.html` in your browser. These tools need no installation, account, or internet connection once downloaded.
